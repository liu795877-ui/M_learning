# Paper screening and set ordering

## Single paper

Extract verifiable metadata and answer:

1. What precise problem is solved, for what system/task, and why does it matter?
2. What does the author claim as contribution? Separate mechanism, theory, experiment, and application.
3. What evidence supports each claim? Cite section/page/figure/table/equation.
4. Is novelty substantive, incremental, compositional, or unconfirmed?
5. How relevant is it to the project goal and current research priority?
6. What prerequisite chain, expected difficulty, code/data availability, and reproduction risk exist?

End with one recommendation: `精读`, `补背景后精读`, `仅作参考`, or `暂缓`, plus the smallest reading path.

## Multiple papers

Build a comparison table with: system time, linearity, known/unknown dynamics, regulation/tracking, on/off-policy, PI/VI/actor-critic, model/data dependence, excitation requirement, stability/convergence result, robot evidence, code, difficulty, baseline suitability, and relevance.

Infer lineage only with evidence. Preserve uncertainty. Recommend an order using foundation, dependency, difficulty, manipulator relevance, code availability, and baseline value. Preserve supervisor order as a separate column.

For the four-paper ADP set, update only proposed content in `adp-paper-set/` until the PDFs are available. Never fabricate titles or relationships.
