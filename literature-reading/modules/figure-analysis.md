# Adaptive figure and experiment analysis

Default to detailed interpretation; escalate critical figures to reviewer-style audit; extract/reproduce data only on request or in reproduction mode.

For each figure/table: cite location; describe panel, axes, units, legends, conditions, and compared methods; state the author's intended claim; quantify absolute/relative differences only from reliable values; note best, second-best, anomalies, and whether evidence supports the claim.

Audit truncation, missing uncertainty/error bars, sample size, random seeds, statistical significance, baseline fairness, hyperparameter budget, ablation completeness, train/test leakage, idealized simulations, disturbance/noise, real-robot evidence, and mismatch with prose.

For screenshots or low-resolution images, distinguish readable facts from estimates. Never invent exact values. If extracting data, record extraction method and uncertainty, and map the generating script when a repository is available.
