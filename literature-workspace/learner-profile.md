# 学习者画像

## 背景与目标

- 背景：软件工程跨机械工程研究生。
- 当前方向：ADP（Adaptive Dynamic Programming）自适应最优控制，研究对象以机械臂为主，任务为控制。
- 当前阶段：导师给出四篇 ADP 论文；已粗读摘要和引言，但方法、公式与理论推导尚未理解。
- 学习节奏：长时集中阅读，核心论文可按半天级流程组织。
- 首要目标：将阅读转化为可发表的研究问题、可复现方法与实验。

## 教学策略

采用：直觉 → 工程场景 → 前置知识链 → 数值例子 → 推导 → 伪代码/代码映射 → 复述纠错。普通内容用 2–3 个理解题；核心算法要求用自己的话复述。
