## 维度检查顺序

1. 先写出 $x,u,A,B,Q,R,K,P$ 的形状。
2. 检查 $x^TQx$、$u^TRu$ 为标量。
3. 检查 $Kx$ 与 $u$ 同维。
4. 检查 $g(x)g^+(x)$ 是状态空间投影。
5. 检查论文矩阵向量化后未知参数数目与秩条件是否匹配。
6. 代码映射时同时记录批量维和单样本维，避免把数学列向量与张量 batch 混淆。
